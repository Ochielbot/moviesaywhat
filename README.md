# MovieSayWhat

A system to search for specific dialogue phrases from movies/TV shows and find the exact scene/clip where that line occurs.

## Features
- Search dialogue phrases from popular movies/TV shows
- Find exact timestamps in scenes
- Link to YouTube clips at the specific moment
- Uses subtitles/transcripts instead of video analysis

## Quick Start
```bash
npm install
npm start
```

## Example Usage
```
Query: "are you serious"
Result: 
- Movie/Show: The Office (US)
- Timestamp: 2:34
- Link: https://youtube.com/watch?v=xyz&t=154s
- Subtitle line: "Are you serious?!"
```
